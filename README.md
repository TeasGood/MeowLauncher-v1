# MeowLauncher

TUI-лаунчер Minecraft: версии с модами, все версии от 1.8.9 до самой свежей,
Fabric / Quilt / Forge / NeoForge, моды с Modrinth живым списком.
Стандартная библиотека Python 3.8+, без прав администратора и root. Единственная
необязательная зависимость — Pillow: без неё читаются PNG и GIF, с ней ещё WebP
и JPEG. В собранный exe она уже вложена.

```
 /\_/\   MeowLauncher 1.0.1
( o.o )  Steve · офлайн

 Версии

 ▸ ● Ванилла 26.3                           26.3
   ● Фабрик и шейдеры       1.21.1 · Fabric · модов: 14
   ● Технолоджи             1.20.1 · NeoForge · модов: 62
   ● Старое доброе                   1.8.9 · Forge
   ＋ Новая версия

 [Enter] играть  [↑↓] выбор  [/] поиск  [N] новая
 [E] меню  [A] аккаунт  [S] настройки  [Esc] назад
```

## Запуск

```
git clone https://github.com/TeasGood/MeowLauncher-v1.git
cd MeowLauncher-v1
python launcher/MeowLauncher.py
```

Windows без Python: `powershell -ExecutionPolicy Bypass -File launcher\MeowLauncher.ps1`
— скрипт сам найдёт или поставит Python для текущего пользователя.
Linux и macOS: `sh launcher/MeowLauncher.sh`.

При первом запуске лаунчер спросит язык (предложит язык системы, рядом поиск по
списку из 35 языков), потом попросит добавить аккаунт.

## Что умеет

- **Версии.** Игра + загрузчик + моды + свои настройки в отдельной папке.
  У каждой своё имя и свой цвет кота, как в PrismLauncher. Копируются целиком.
  Список игр — все релизы от 1.8.9 до самой свежей, прямо с серверов Mojang;
  снапшоты включаются в настройках.
- **Моды с Modrinth живым списком.** Вкладка модов открывается сразу на самых
  скачиваемых модах для этой версии игры и загрузчика. Пока печатаете название,
  список приходит с Modrinth — запрос уходит, когда вы перестали набирать.
  Зависимости ставятся вместе с модом, включение и выключение одной клавишей.
  Без интернета вкладка честно пишет, что связи нет.
- **Пачкой или по одному.** `Tab` включает режим отметки: `Enter` ставит
  галочки на нужных модах, второй `Tab` качает все отмеченные разом. Если нужен
  один мод — просто `Enter` на нём, как раньше.
- **Предпросмотр мода.** Стрелка вправо открывает карточку: иконка, описание и
  скриншоты, между ними ходят стрелками. В терминалах с поддержкой графики
  картинка рисуется по-настоящему, пиксель в пиксель: Sixel (Windows Terminal
  1.22+, xterm, foot, mintty, WezTerm, Konsole), протокол Kitty (Kitty, Ghostty,
  WezTerm) или встроенные картинки iTerm2. Если терминал графику не умеет,
  остаётся прежняя отрисовка полублоками.
- **Сборки целиком.** В списке версий есть «Импортировать сборку»: поиск по
  Modrinth живым списком или файл `.mrpack` с диска. Берутся версия игры,
  загрузчик, все моды и папка `overrides` — конфиги, ресурспаки, настройки.
  Сборки CurseForge тоже читаются из `.zip`; их моды качаются, только если в
  настройках задан ключ API, иначе ставится всё остальное и лаунчер скажет,
  сколько модов пропустил.
- **Аккаунты.** Офлайн-ник заводится за полминуты.
- **Загрузчики.** Fabric, Quilt, Forge, NeoForge — с выбором конкретной версии.
  Forge и NeoForge ставятся их официальным установщиком, но библиотеки лаунчер
  скачивает сам в 12 потоков ещё до его запуска: на NeoForge 21.1 это 70 файлов
  и 25 МБ, 3,6 секунды вместо 33 у однопоточного установщика.
- **Java.** Нужная версия (8, 17, 21, 25) определяется по json игры и скачивается
  с adoptium.net в папку лаунчера. Системная Java не трогается.
- **Запущенную игру можно оставить или остановить.** Пока она идёт, лаунчер
  показывает её лог; по `X` возвращаетесь к списку версий, а игра продолжает
  работать, по `S` — останавливаете её. В списке такая версия помечена, и
  `Enter` на ней возвращает к той же игре.
- **Расширенные настройки версии.** Память, своя Java, аргументы JVM и игры,
  размер окна, полный экран, сервер для входа при запуске, команды до и после.
  Память берётся из списка или вводится руками, от 512 до 65536 МБ.
- **Опасная зона.** В настройках, красным: снести все версии разом, удалить
  лаунчер вместе с папкой данных (спросит трижды, последний вопрос — арифметика)
  и секретная кнопка, которую лучше не нажимать.
- **Настройки лаунчера.** Отдельный раздел: цвет текста, живой фон из гифки,
  его яркость и выключатель всех картинок.
- **Фон ставится в три движения.** «Файл фона» открывает папку `wallpapers`
  рядом с данными: бросьте туда гифку или картинку — она появится в списке.
  Рядом кнопка «Выбрать файл на компьютере» с обычным окном выбора файла, а по
  `O` картинка открывается в отдельном окне в полном качестве.
- **Интерфейс занимает весь терминал.** Подсказки прижаты к нижнему краю, фон
  растянут на всё окно. Размер окна меняется на ходу — лаунчер сам
  перерисовывается, в том числе при переходе в полноэкранный режим.
- **Коты вместо кружков.** В списке версий у каждой — кот `ᓚᘏᗢ` своего цвета,
  цветов 32.
- **Кот в углу кликабельный.** Мышь работает прямо в терминале: один клик по
  коту слева сверху возвращает на главный экран с любого места. Десять кликов
  подряд открывают то, чего там быть не должно.
- **Быстрый запуск.** `--play «имя версии»` без меню.
- **Любая раскладка.** Горячие клавиши работают не только на английской:
  лаунчер спрашивает у системы, какая клавиша нажата физически, поэтому `N`,
  `S`, `X` и стрелки `hjkl` срабатывают на русской, украинской, белорусской,
  казахской, сербской, болгарской, греческой, арабской, тайской, грузинской,
  армянской раскладках и на иврите. Проверено на пятнадцати раскладках Windows.
  Если система ответить не может (Linux, macOS), работает встроенная таблица.
- **Терминал.** Текст не вылезает за край окна при любой ширине; `--nocolor`
  убирает цвета, `--ascii` — псевдографику.

## Ключи командной строки

| Ключ | Что делает |
| --- | --- |
| `-p`, `--play [ИМЯ]` | запустить версию сразу; без имени — последнюю |
| `-l`, `--list` | показать версии и выйти |
| `--lang КОД` | язык для этого запуска: `ru`, `en`, `zh-Hans`… |
| `--nocolor` | без цветов и escape-кодов |
| `--ascii` | только ASCII, без псевдографики |
| `--threads N` | сколько файлов качать параллельно (по умолчанию 12) |
| `--home ПАПКА` | другая папка данных |
| `-V`, `--version` | версия |
| `-h`, `--help` | справка |

Переменные окружения: `MEOW_HOME`, `MEOW_LANG`, `MEOW_MS_CLIENT_ID`,
`MEOW_CF_KEY`, `NO_COLOR`.

## Картинки и звук

Декодеры PNG и GIF написаны прямо здесь, в [media.py](launcher/meowlauncher/media.py):
PNG всех типов (серый, палитра, RGB, RGBA, глубина 1/2/4/8/16), GIF с анимацией,
прозрачностью, чересстрочной развёрткой и всеми способами смены кадра. Сверено
с Pillow попиксельно — расхождений нет. WebP и JPEG читаются через Pillow, если
он установлен; в exe он вложен, поэтому там открывается всё.

Вывод картинок — в [graphics.py](launcher/meowlauncher/graphics.py). Лаунчер
спрашивает терминал, что тот умеет (запрос DA1 и запрос протокола Kitty), и
выбирает лучший способ: Kitty, картинки iTerm2 или Sixel со своим кодировщиком —
прореживание по медианному сечению до 160 цветов, упаковка повторов, полосы по
шесть строк. Если терминал не ответил, остаются половинные блоки `▀`.
Способ можно задать руками: поле `image_mode` в `config.json` принимает
`auto`, `sixel`, `kitty`, `iterm` или `blocks`.

Живой фон включается в «Настройках лаунчера»: гифка кладётся под интерфейс,
яркость от 5 до 100 % (по умолчанию 22 — так текст остаётся читаемым). Фон
анимируется на экранах со списками и растягивается на весь терминал; выключатель
«Показывать картинки» гасит разом и фон, и иконки модов — удобно для медленного
или старого терминала.

Разбором занимается Pillow, если он есть: гифка 1920×1080 на 30 кадров читается
примерно за секунду вместо двадцати и занимает 11 МБ вместо нескольких гигабайт
(кадры хранятся байтами и ужимаются до 480 пикселей по длинной стороне). Без
Pillow работают свои декодеры PNG и GIF — медленнее, но без зависимостей.

Картинку можно открыть и целиком, в отдельном окне: `O` в карточке мода или в
списке фонов. Окно рисует Tkinter, анимация гифки в нём тоже играет.

Звук для секретной кнопки берётся из файла `secret.mp3` рядом с лаунчером или в
папке данных (путь можно задать в настройках). На Windows он играет через `winmm`
без сторонних библиотек, громкость настраивается, длительность шоу равна длине
трека. На Linux и macOS лаунчер ищет `ffplay`, `mpv`, `mpg123`, `afplay` или
`cvlc`; если ничего нет — шоу идёт молча. Сам файл в репозиторий не кладётся.

## Что проверено в коде

- Имя файла мода приходит из чужого API, поэтому берётся только его последняя
  часть и только с расширением `.jar`, `.zip` или `.litemod`: `../` из ответа
  сервера никуда не уведёт.
- Пути библиотек из json Mojang и из установщиков Forge проверяются на выход за
  пределы папки `libraries`, архив Java распаковывается с той же проверкой.
- Качать и ходить по сети можно только по `http` и `https`: ссылка вида
  `file://` из чужого ответа будет отклонена.
- `config.json`, `accounts.json` и `instance.json` пишутся во временный файл и
  переименовываются поверх, так что обрыв питания не оставит битый json.
- Сбой внутри экрана больше не роняет лаунчер: показывается ошибка, полная
  трассировка уходит в `logs/crash-*.log`, работа продолжается.

## Скрытые кнопки: Microsoft и CurseForge

Вход через Microsoft и поиск модов на CurseForge написаны и работают, но их
кнопки убраны из интерфейса: обоим нужен ключ, которого у сборки пока нет.
Код остался на месте, включается двумя флагами в начале
[config.py](launcher/meowlauncher/config.py):

```python
SHOW_MICROSOFT = False
SHOW_CURSEFORGE = False
```

Поставьте `True` — и вернутся: пункт «Войти через Microsoft» в аккаунтах,
«Найти моды на CurseForge» в модах и обе строки с ключами в настройках.

Чтобы вход Microsoft заработал, нужен client ID приложения Azure:
[portal.azure.com](https://portal.azure.com) → App registrations → New
registration → **Public client (mobile & desktop)**, redirect URI
`https://login.microsoftonline.com/common/oauth2/nativeclient`. Подписка и карта
не нужны. ID кладётся в `BUILTIN_MS_CLIENT_ID` в том же файле, в настройки
лаунчера или в `MEOW_MS_CLIENT_ID`. Идентификатор публичного клиента не секрет —
его держат в открытом коде и PrismLauncher, и HMCL.

Ключ CurseForge берётся на [console.curseforge.com](https://console.curseforge.com)
(бесплатно) и кладётся в настройки или в `MEOW_CF_KEY`. В открытый код его
класть нельзя — это запрещено правилами CurseForge.

## Где лежат файлы

```
MeowLauncher/
├─ config.json        язык, память, ключи
├─ accounts.json      аккаунты и сессии
├─ runtime/           Java 8, 17, 21
├─ game/
│  ├─ versions/       версии и загрузчики
│  ├─ libraries/      библиотеки
│  └─ assets/         звуки и текстуры
├─ instances/
│  └─ <версия>/
│     ├─ instance.json
│     └─ minecraft/   saves, options.txt, mods
├─ secret.mp3         музыка секретной кнопки, если положили
├─ wallpapers/        картинки и гифки для фона
├─ lang/              свои переводы (*.json)
└─ logs/              логи запусков и crash-*.log, если лаунчер споткнулся
```

Windows: `%LOCALAPPDATA%\MeowLauncher` · Linux: `~/.local/share/MeowLauncher` ·
macOS: `~/Library/Application Support/MeowLauncher`. Чтобы удалить всё — сотрите
эту папку.

**Перенос на другой диск.** Настройки → «Папка с данными» → «Перенести на другой
диск или в другую папку». Открывается системное окно выбора папки (или строка
для пути), лаунчер показывает объём, спрашивает подтверждение, копирует файлы с
прогрессом, стирает старую копию и перезапускается уже из нового места. Запись о
новом месте лежит в `location.txt` в стандартной папке — так лаунчер находит
данные при следующем запуске. Там же пункт «Вернуть в стандартное место».
Подпапка `app` (если лаунчер установлен через `install.ps1`/`install.sh`) не
переезжает — программа остаётся где была, переезжают только данные. Переменная
`MEOW_HOME` имеет приоритет: если она задана, перенос через настройки отключён.

Переход с MeowCraftLauncher: Настройки → «Перенести из MeowCraftLauncher»,
скачанные версии и Java переедут, качать заново не нужно.

## Структура репозитория

```
launcher/MeowLauncher.py            точка входа
launcher/MeowLauncher.ps1 / .sh     запуск без установленного Python
launcher/meowlauncher/              код лаунчера
launcher/meowlauncher/media.py      свои декодеры PNG и GIF
launcher/meowlauncher/graphics.py   Sixel, Kitty и iTerm2 в терминале
launcher/meowlauncher/viewer.py     окно Tkinter и выбор файла
launcher/meowlauncher/packs.py      импорт сборок Modrinth и CurseForge
launcher/meowlauncher/lang/         переводы, по модулю на язык
MeowLauncher.exe                    собранный лаунчер для Windows
assets/logo.ico                     значок, нужен только для сборки exe
install.ps1, install.sh             установка одной командой
.github/workflows/build.yml         проверки и сборка exe
```

### Собрать exe у себя

```
python -m venv buildenv
buildenv\Scripts\python -m pip install pyinstaller
buildenv\Scripts\python -m PyInstaller --onefile --console --name MeowLauncher ^
    --paths launcher --icon assets\logo.ico launcher\MeowLauncher.py
```

Готовый файл окажется в `dist\MeowLauncher.exe`, около 18 МБ. Чтобы в нём
работали WebP и JPEG, в окружение сборки ставится ещё `pillow`, а в команду
добавляется `--hidden-import PIL.Image --hidden-import PIL.ImageTk
--exclude-module numpy`. Без `pillow` выйдет около 9 МБ, но часть картинок на
Modrinth не покажется, а гифки будут читаться заметно дольше. На Linux то же
самое без `--icon`.

Exe не подписан, поэтому Windows Smart App Control (включён на части свежих
установок Windows 11) его не запустит. Варианты: запускать из исходников,
подписать сертификатом или раздавать пользователям без этой защиты.

### Как добавить язык

Скопируйте `launcher/meowlauncher/lang/en.py` в `<код>.py`, переведите значения,
добавьте модуль в `_MODULES` в `lang/__init__.py`. Полноту набора ключей
проверяет `missing()` из того же модуля (и CI при каждой сборке).

Без правки кода: положите `<код>.json` вида `{"native": "...", "english": "...",
"strings": {...}}` в папку `lang` рядом с данными лаунчера — он подхватится при
следующем запуске.

## Публикация

Репозиторий проекта: [TeasGood/MeowLauncher-v1](https://github.com/TeasGood/MeowLauncher-v1).

1. **Содержимое этой папки кладётся в корень репозитория.** Одного
   `MeowLauncher.py` мало: он всего лишь точка входа и без папки
   `launcher/meowlauncher/` падает с `ModuleNotFoundError`. Работает в одиночку
   только `MeowLauncher.exe` — внутри него уже всё лежит.
2. Кнопка «MeowLauncher.exe» на сайте ведёт прямо на файл в репозитории
   (`raw/main/MeowLauncher.exe`), кнопка с исходниками — на
   `archive/refs/heads/main.zip`. Релиз для этого не нужен.
3. Сборка бинарников: `git tag v1.0.1 && git push origin v1.0.1`. GitHub Actions
   соберёт `MeowLauncher.exe` и `MeowLauncher-linux` и приложит к релизу.
4. Exe не подписан. На машинах с включённым Smart App Control Windows откажется
   его запускать с ошибкой `0x800711c7` — это не вирус, а требование подписи.
   Там помогает запуск из исходников.

**Сайта в репозитории нет.** Его исходники лежат отдельно и заливаются прямо на
хостинг, минуя GitHub: так разметку, тексты и оформление нельзя скачать вместе с
кодом и поднять поддельную копию в пару кликов. GitHub Pages включать не нужно —
ссылки на сайте и так ведут в этот репозиторий. Если сайт понадобится собрать
заново, его файлы лежат у автора в папке `SITE2`.

**Музыки секретной кнопки здесь тоже нет** — трек чужой, в открытый репозиторий
его класть нельзя. Лаунчер подхватит файл `secret.mp3`, если положить его рядом
с exe или в папку данных.
